## 2. 학습데이터 공통 개요

- **데이터 이름:** 유방암 IHC 세포 검출·분류 학습데이터셋(ER/PR, Ki-67, HER2)
- **데이터 유형(모달리티):** 이미지 및 구조화 라벨 데이터
- **데이터 제공 의료기관:** 가톨릭대학교 서울성모병원
- **데이터 형식:** 학습 입력은 PNG 이미지이며, 정답 라벨은 JSON 형식이다. 원천자료는 Aperio SVS 형식의 디지털 병리 전장 슬라이드 영상(Whole Slide Image, WSI)과 AIVIS 주석 결과 JSON으로 구성된다. 주석 JSON은 `images`, `categories`, `annotations` 항목을 갖는 COCO 유사 구조이며, 세포별 경계상자(`bbox`), 클래스(`category_id`), 비종양 여부(`was_nonT`)를 포함한다. Ki-67 주석에는 염색 양성도 순위(`positivity_rank`)가 추가로 포함된다.
- **수집 목적:** 유방암 IHC 슬라이드에서 종양세포와 비종양·기타 세포를 구분하고, 바이오마커별 염색 강도 또는 양성 여부를 세포 단위로 검출·분류하는 AI 모델의 개발, 학습 및 검증에 활용하기 위해 수집하였다.
- **수집 방법:** 가톨릭대학교 서울성모병원에서 확보한 유방암 ER, PR, Ki-67 및 HER2 IHC 염색 병리 슬라이드를 디지털 스캐너로 전산화하고, AIVIS 주석 결과를 이용하여 세포별 위치, 경계상자, 염색 등급 또는 양성 여부와 비종양 여부를 구성하였다. 주석을 수행·검수한 병리전문의 또는 숙련 주석자의 구성과 수, 원천 데이터의 적법한 이용 근거, 동의·면제 여부 및 IRB 승인번호는 `[확인 후 기입]`한다.
- **원천 슬라이드 수량:** 실제 학습 패치와 연결되는 원본 WSI 69장(ER 9장, PR 7장, Ki-67 46장, HER2 7장)이다. 파일명에 포함된 검사 접수 식별자를 기준으로 하면 60개의 상이한 식별자로 구성되며, 이는 환자 수와 동일하다고 단정할 수 없다.
- **원천 데이터 크기:** 원본 WSI 약 64.44 GB(ER/PR 약 11.74 GB, Ki-67 약 45.64 GB, HER2 약 7.06 GB)이다. 아래의 학습데이터 크기는 원본 WSI가 아니라 변환된 PNG·JSON 파일을 기준으로 별도 산정하였다.
- **영상 획득 장비 및 조건:** 69장 모두 Leica Biosystems의 Aperio GT450 스캐너(헤더 표기 소프트웨어 버전 v1.5.1)로 40배 스캔되었다. 원본 해상도는 0.262703~0.262704 μm/pixel이고, 원본 크기는 가로 50,008~173,610 pixel, 세로 27,915~87,029 pixel이다. SVS는 256×256 tile, JPEG/YCC 품질 91의 피라미드 영상이며 3개 또는 4개 해상도 레벨로 구성된다.
- **디지털 스캔 시기:** WSI 헤더의 `aperio.Date` 기준 2025년 12월 22일~2026년 1월 16일(GMT+09:00)이다. 이 기간은 디지털 스캔 시기이며, 검체 채취일 또는 환자 진료기간을 의미하지 않는다.
- **원천 영상 품질정보:** 69장 모두 ICC 색상 프로파일을 포함한다. SVS 헤더의 `Scan Warning`은 68장이 `NONE`, Ki-67 1장이 `IQ_TILT`로 확인되어 해당 슬라이드의 초점·기울기 및 학습 적합성에 대한 추가 육안 검토와 처리 기록이 필요하다.
- **데이터 선정·제외 기준(코드 기준):** 원본 SVS와 AIVIS 주석 JSON이 모두 존재하고 ER, PR, Ki-67 또는 HER2 표지자로 식별되는 슬라이드만 변환 대상으로 선정하였다. 세포 주석이 없는 슬라이드는 제외하고, 슬라이드 격자 분할 후 주석 세포가 10개 미만인 패치는 저장하지 않았다.
- **공통 전처리 방법:**
  1. 원본 전장 슬라이드의 해상도 정보를 이용하여 0.5 μm/pixel로 정규화하였다.
  2. 슬라이드를 격자 방식으로 분할하고 512×512 pixel, 8-bit RGB PNG 패치로 변환하였다.
  3. 각 패치에 포함된 세포 경계상자를 패치 좌표계에 맞추고, 중심 좌표와 너비·높이를 0~1 범위로 정규화하여 JSON으로 저장하였다.
  4. 주석 세포가 10개 미만인 패치는 학습데이터 생성 대상에서 제외하였다.
  5. 원본 슬라이드의 ICC 색상 프로파일을 perceptual rendering intent로 sRGB에 변환하고, 크기 변환 시 LANCZOS 보간법을 사용하였다.
  6. 학습 단계에서 훈련 데이터에 한하여 좌우·상하 반전, 90도 회전, 밝기·대비·색조·채도·감마 조절, 색상 채널 변화, 잡음 및 블러 등의 증강을 적용한다. 검증 데이터에는 임의 증강을 적용하지 않는다. 단, Ki-67의 실제 학습 파이프라인 적용 여부는 별도 확인이 필요하다.
- **라벨 변환 방법:** ER/PR의 `non_tumor`, HER2의 `class4`, Ki-67의 `non_tumor`는 학습용 `other` 클래스로 통합하도록 전처리 코드가 구성되어 있다. 위치와 크기는 패치 내부의 정규화 좌표(`cx`, `cy`, `w`, `h`)로 변환된다. 계층형 ER/PR·HER2 학습 로더에서는 `was_nonT=1`을 최종 `other` 라벨로 우선 적용한다.
- **검수 방법(코드 및 저장 폴더 기준):** ER/PR 데이터에는 클래스별 중심점을 표시한 검수용 오버레이를 생성하고, DAB 갈색 발현 기준을 충족하지 않는 class 1·2·3 라벨을 class 0으로 재지정하며, 사용자가 오버레이를 삭제한 패치의 PNG·JSON 쌍을 함께 제거하는 검수 코드가 존재한다. 현재 ER/PR 데이터 15,309쌍과 동일한 수의 검수 오버레이 15,309장이 저장되어 있어 전체 패치의 오버레이 생성은 확인된다. 다만 노트북에 실행 출력이 저장되어 있지 않아 실제 재지정·수동 제외 건수와 병리전문의 최종 승인 여부는 별도 검수 기록으로 확인해야 한다. Ki-67 및 HER2에 동일한 수동 검수 절차를 적용했는지도 확인이 필요하다.
- **개인정보·비식별화 관련 확인:** 패치 생성 코드는 WSI의 조직 영역만 읽으며, 원본 SVS에 포함된 label·macro 연관 이미지는 학습 PNG로 추출하지 않는다. 변환된 PNG·JSON에는 환자명·주민등록번호 같은 직접 식별 필드를 새로 기록하지 않지만, 파일명에는 검사 접수 식별자가 유지된다. 따라서 이를 가명정보로 관리하고 재식별 매핑정보의 분리보관, 접근권한 통제 및 반출 시 파일명 치환 여부를 문서화해야 한다. 원본 WSI의 label·macro 이미지에 직접 식별정보가 존재하는지도 별도 점검해야 한다.
- **데이터 요약:** 유방암 조직의 ER, PR, Ki-67 및 HER2 IHC 염색 전장 슬라이드에서 생성된 패치 이미지와 세포 단위 경계상자·클래스 라벨로 구성된다. 학습데이터에는 바이오마커별 종양세포 염색 등급 또는 양성 여부와 비종양·기타 세포 정보가 포함된다.
- **전체 데이터 수량:** 이미지·라벨 124,422쌍(총 파일 248,844개)
- **전체 데이터 크기:** 약 51.6 GB(파일의 논리적 크기 기준, 검수용 오버레이 및 파생 마스크 제외)
- **합성데이터:** 생성형 AI 또는 별도 생성모델로 제작한 합성데이터는 포함하지 않는다. 학습 시 적용하는 회전·반전·색상 변환 등의 데이터 증강은 원본 학습 이미지의 변형이며, 별도의 합성 이미지 파일로 저장하지 않는다.

## 4. Ki-67 AI 학습데이터

- **데이터 이름:** 유방암 Ki-67 IHC 세포 검출·양성/음성 분류 데이터셋
- **원천 영상 획득 정보:** 서울성모병원에서 Aperio GT450, 40배로 스캔된 Ki-67 WSI 46장을 사용하였다. 헤더상 스캔 기간은 2025년 12월 22일~2026년 1월 16일이다.
- **가장 최근 업데이트 시기:** 2026년 4월 14일
- **데이터 수량:** PNG 이미지 94,712장 및 JSON 라벨 94,712개(총 94,712쌍, 원천 슬라이드 46장)
- **데이터 크기:** 약 39.31 GB(PNG 약 36.52 GB, JSON 약 2.79 GB)
- **데이터 요약:** Ki-67 염색 병리 패치와 세포별 경계상자, 종양세포의 염색 양성·음성 정보, 비종양 여부 및 positivity rank 정보로 구성된다.
- **클래스 정의:** negative(Ki-67 음성 종양세포), positive(Ki-67 양성 종양세포), other(비종양·기타 세포)
- **클래스별 분포(유효 학습 라벨 기준):** 총 23,921,499개. `was_nonT=1`인 객체를 other로 환산한 수치이다.

| 클래스 | 수량 | 비율 |
|---|---:|---:|
| negative | 3,089,775 | 12.92% |
| positive | 1,494,404 | 6.25% |
| other | 19,337,320 | 80.84% |

> **제출 전 확인사항:** 현재 저장된 Ki-67 JSON의 원본 `class_id` 분포는 negative 19,244,267개, positive 4,677,232개, other 0개이며, 별도로 `was_nonT=1`인 객체가 19,337,320개 존재한다. 위 표는 비종양 플래그를 other로 변환한다는 전제의 분포다. 현재 작업공간에는 Ki-67 학습 노트북이 없어 실제 학습 로더가 이 변환을 수행했는지 확인할 수 없으므로, 실제 사용한 학습 코드 및 모델 버전을 기준으로 반드시 확정해야 한다.

> **영상 품질 확인사항:** 원본 Ki-67 WSI 중 1장의 헤더에 `Scan Warning=IQ_TILT`가 기록되어 있다. 해당 영상의 육안 품질검사 결과, 재스캔 여부 및 최종 학습 포함·제외 판단을 데이터 이력에 남겨야 한다.

## 6. 제출 전 필수 확인 및 보완 항목

1. 제품·서비스의 허가·신고 문서와 동일한 공식 명칭
2. 제공 회사·기관의 공식 명칭과 담당자 연락처
3. 검체 채취기간, 대상 환자·검체의 임상적 선정·제외 기준 및 환자 수
4. 주석자의 자격·인원, 주석 지침, 다중 주석 합의 및 병리전문의 검수 방법
5. 개인정보 비식별화 방법, 환자 동의 또는 동의 면제, IRB 승인번호와 데이터 이용계약
6. 원본 WSI의 label·macro 이미지 개인정보 점검 및 검사 접수 식별자 가명처리 방법
7. 환자·검체·슬라이드 단위의 학습/검증/시험 세트 분할 수량 및 외부 시험데이터 여부
8. 실제 모델 학습에 사용한 데이터 버전과 파일 목록을 고정할 수 있는 버전 식별자 또는 해시
9. Ki-67의 `was_nonT` 처리 방식과 실제 학습 시 사용한 클래스 분포
10. `IQ_TILT` 경고가 있는 Ki-67 WSI 1장의 품질검사 및 포함·제외 결정 기록
11. ER/PR 자동 재지정·수동 제외 건수와 HER2·Ki-67 검수 이력
12. 데이터 업데이트 일자를 파일 수정일이 아닌 내부 데이터 배포·승인 이력과 대조

## 7. 본 초안의 확인 근거

- **의료기관:** 사용자 확인에 따라 가톨릭대학교 서울성모병원으로 기재하였다.
- **원천 영상 정보:** 실제 학습 패치 파일명과 연결되는 69개 SVS의 OpenSlide 헤더에서 `aperio.ScannerType`, `aperio.AppMag`, `aperio.MPP`, `aperio.Date`, `aperio.Time Zone`, `aperio.Scan Warning`, 피라미드 레벨, 영상 크기 및 ICC 프로파일 존재 여부를 전수 확인하였다.
- **패치 생성 및 라벨 변환:** `Data_processing.ipynb`의 SVS·주석 JSON 대응, 표지자별 분류, 0.5 μm/pixel 정규화, 512×512 패치 생성, 최소 세포 수 조건, ICC 변환 및 클래스 매핑 코드를 확인하였다.
- **데이터 수량·크기·분포:** 현재 `er_pr`, `ki67`, `her2` 데이터 디렉터리의 PNG·JSON 파일 수와 논리적 파일 크기, JSON 내 세포 객체를 전수 집계하였다.
- **검수 절차:** `data_review.ipynb`의 오버레이 생성, DAB 기반 라벨 재지정 및 수동 삭제 연동 코드와 현재 저장된 ER/PR 검수 오버레이 수를 확인하였다.
